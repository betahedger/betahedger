# 안녕하세요, betahedger입니다.

아주대학교에서 **금융공학을 전공**하고 **인공지능융합전공을 복수전공**하고 있습니다.

투자자산운용사, 금융투자분석사, AFPK 자격시험을 준비하며 금융시장·투자분석의 기초를 쌓았고, 현재는 이를 **Python과 데이터 분석으로 확장해 투자 아이디어를 직접 검증하는 과정**에 관심을 두고 있습니다.

특히 **퀀트 투자, 파생상품, 시스템 트레이딩, 금융 데이터 분석**을 중심으로 공부하고 있으며, 단순히 모델을 만드는 것보다 **가정 → 구현 → 검증 → 실행 → 한계 분석**의 전 과정을 명확하게 설명할 수 있는 프로젝트를 만들고자 합니다.

## 금융 자격시험

- **투자자산운용사 제43회 자격시험 합격**
- **금융투자분석사 제24회 자격시험 합격**
- **AFPK 제93회 자격시험 합격**

## 주요 프로젝트

### 1. SAGE Price Model

**금융이론을 이용한 가격예측·모형 결합**

CAPM, Fama-French 방식 3요인 모형, APT 방식 거시요인 모형, DDM, RIM의 예측값을 과거 검증 오차에 따라 가중 결합해 기대주가를 산출하는 금융공학 프로젝트입니다.

[프로젝트 보기](https://github.com/betahedger/sage-price-model)

---

### 2. Futures Trend Backtest

**매매전략 설계·백테스트·거래비용·리스크 분석**

선물 가격 데이터에 이동평균 추세추종 전략을 적용하고, 미래정보 참조 방지와 거래비용을 반영해 수익·위험 특성을 검증하는 백테스트 프로젝트입니다.

[프로젝트 보기](https://github.com/betahedger/futures-trend-backtest)

---

### 3. Futures Paper Trading System

**API·실시간 데이터·모의주문·포지션·리스크 관리**

시장데이터와 매매신호를 모의주문·체결·포지션·손익·리스크 관리까지 연결한 Paper Trading 시스템입니다. 현재는 Mock Broker로 재현 가능하게 구현했으며, 실제 REST API를 별도 브로커 어댑터로 연결할 수 있도록 구조를 분리했습니다.

[프로젝트 보기](https://github.com/betahedger/futures-paper-trading-system)

## 현재 목표

금융시장 아이디어를 **Research → Backtest → Execution** 흐름으로 구현하고, 실제 데이터와 API 환경으로 확장 가능한 투자전략·리스크 관리 시스템을 만드는 것이 목표입니다.
