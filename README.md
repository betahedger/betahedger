## 주요 프로젝트

### 1. SAGE Price Model

**금융이론을 이용한 가격예측·모형 결합**

여러 금융모형의 주가 예측값을 **과거 검증 오차에 따라 가중 결합**해 기대주가를 산출하는 금융공학 프로젝트입니다.

사용한 주요 접근:
- CAPM
- Fama-French 방식 3요인 모형
- APT 방식 거시요인 모형
- 배당할인모형(DDM)
- 잔여이익모형(RIM)

각 모형의 과거 상대오차를 기반으로 성과가중치를 계산하고, 해당 시점 이전에 결과가 확인된 정보만을 이용해 결합 예측을 구성합니다.

[프로젝트 보기](https://github.com/betahedger/sage-price-model)

---

### 2. Futures Trend Backtest

**매매전략 설계·백테스트·거래비용·리스크 분석**

선물 가격 데이터를 이용해 **이동평균 추세추종 전략**의 수익·위험 특성을 검증하는 백테스트 프로젝트입니다.

주요 구현:
- 20일 / 60일 이동평균 교차 전략
- Long / Short 포지션
- `signal.shift(1)`을 통한 미래정보 참조 방지
- 수수료 및 슬리피지 반영
- CAGR / Volatility / Sharpe Ratio / MDD 계산

단순한 과거수익률 제시보다 백테스트 편향, 거래비용, 전략의 한계를 함께 확인하는 데 초점을 두었습니다.

[프로젝트 보기](https://github.com/betahedger/futures-trend-backtest)

### 3. Futures Paper Trading System

**API·실시간 데이터·모의주문·포지션·리스크 관리**

매매신호를 단순 백테스트에서 끝내지 않고, **모의주문·체결·포지션·손익·리스크 관리까지 연결**한 Paper Trading 시스템입니다.

주요 구현:
- Broker 인터페이스 기반 주문 구조
- Mock Broker를 이용한 시장가 모의체결
- 이동평균 신호 기반 목표 포지션 생성
- 평균단가 및 실현·미실현손익 계산
- 최대 포지션 및 일일 손실 한도 관리
- 거래내역과 시점별 포지션 상태 로그 저장

브로커 인터페이스를 별도 계층으로 분리해, 향후 외부 증권·선물사나 거래소 API를 연결하더라도 기존 전략·포트폴리오·리스크 관리 로직을 재사용할 수 있도록 구성했습니다.

[프로젝트 보기](https://github.com/betahedger/futures-paper-trading-system)
